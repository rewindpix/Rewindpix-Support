# Rewindpix Feedback & Support

Welcome! This repository is the public place to report problems, suggest new features, and contact us about security concerns.

You do not need to be a developer to use this page. If you have a GitHub account, you can submit feedback by following the steps below.

## Something isn't working

If the Rewindpix APP is behaving incorrectly, please report it as a Bug Report.

Examples:

- The app crashes
- A photo does not save correctly
- The camera will not connect
- A button does nothing
- Something looks different from what you expected

### How to report a bug

1. At the top of this GitHub page, click [Issues](https://github.com/n3xta/Rewindpix-Support/issues).
2. Click New issue.
3. Choose [Bug Report](https://github.com/n3xta/Rewindpix-Support/issues/new?template=bug_report.yml).
4. Fill out the form with as much information as you can.
5. Click Submit new issue.

Screenshots and screen recordings are very helpful. You can drag them directly into the text box.

Before uploading anything, please make sure it does not contain private information such as passwords, addresses, Wi-Fi passwords, private photos, or other personal information.

## Have an idea for Rewindpix?

We would love to hear it.

Feature requests can include things like:

- A new camera feature
- A new film/filter option
- Changes to the Rewindpix app
- Accessibility improvements
- Anything that would make Rewindpix easier or more enjoyable to use

### How to suggest a feature

1. Click [Issues](https://github.com/n3xta/Rewindpix-Support/issues) at the top of this page.
2. Click New issue.
3. Choose [Feature Request](https://github.com/n3xta/Rewindpix-Support/issues/new?template=feature_request.yml).
4. Tell us what you would like RewindPix to do and, if possible, why it would be useful to you.
5. Click Submit new issue.

You do not need to know how the feature should be built. Just describe what you would like to be able to do.

If someone has already suggested the same idea, you can open their issue and click the 👍 reaction instead of creating another one.

## Found a security or privacy problem?

Please do NOT report security vulnerabilities as public issues.
See [here](SECURITY.md) instead.
