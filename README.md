# Rewindpix Feedback & Issue Tracker

This repository is the public issue tracker for Rewindpix.

## Found a bug?
Please open a Bug Report and include:
- Your device
- OS version
- Rewindpix version
- Steps to reproduce
- Screenshots / videos if possible

## Have an idea?
Open a Feature Request.

## Security issues
Please do NOT report security vulnerabilities as public issues.
See [here](SECURITY.md) instead.
